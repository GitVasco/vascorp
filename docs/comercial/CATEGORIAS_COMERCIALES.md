# Categorías Comerciales

## Propósito

El módulo **Categorías Comerciales** permite definir los niveles de clasificación para clientes y grupos empresariales, por ejemplo: distribuidor, mayorista o minorista. Cada categoría establece requisitos, referencias de crédito y beneficios comerciales.

## Cómo funciona

Cada categoría se configura con un nombre, código, orden y color para identificarla en el sistema. Además, puede incluir:

- Un monto mínimo anual de compras como referencia comercial.
- Una línea mínima de crédito como piso orientativo.
- Descuento de venta y descuento por pronto pago.

La categoría se asigna de forma manual desde la gestión de clientes o grupos. Si un cliente pertenece a un grupo empresarial, prevalece la categoría asignada al grupo; si no pertenece a uno, se utiliza su categoría individual.

El sistema conserva el historial de cambios y permite marcar asignaciones que requieren revisión o que fueron aprobadas como excepción.

## Acciones disponibles

- **Crear categoría:** registra una nueva clasificación comercial con sus reglas y beneficios.
- **Editar categoría:** actualiza nombre, descripción, orden, color, requisitos, línea mínima o descuentos.
- **Activar o desactivar categoría:** controla si una categoría puede seguir utilizándose en nuevas asignaciones.
- **Configurar monto anual mínimo:** establece la referencia de compras para la categoría.
- **Configurar línea mínima de crédito:** define un piso orientativo para las decisiones de línea de crédito.
- **Usar línea sugerida:** propone una referencia aproximada de 2.5 meses de compras anuales.
- **Consultar clientes, grupos y casos por revisar:** visualiza cuántas entidades tienen asignada cada categoría y cuáles necesitan evaluación.
- **Asignar categoría a cliente o grupo:** se realiza desde los módulos de gestión correspondientes.

> La línea mínima no reduce una línea de crédito ya mayor; solo genera una alerta cuando se intenta aprobar un monto menor.
