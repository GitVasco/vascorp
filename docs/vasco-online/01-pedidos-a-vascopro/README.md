# Pedidos a VascoPro

Documentos escritos desde **vascorp** para pedir a VascoPro un endpoint, estado o campo nuevo.

## Reglas

- Un archivo por pedido.
- Naming: `YYYY-MM-DD-tema.md`.
- No implementar en vascorp hasta que exista la respuesta correspondiente en [`../02-respuestas-vascopro/`](../02-respuestas-vascopro/).
- Cuando VascoPro responda, el usuario copia la respuesta en `02-respuestas-vascopro/` y se puede implementar.
